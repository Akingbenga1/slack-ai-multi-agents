# Document Summary

Use this when someone has a file (PDF, Word, Excel, or text) and wants a plain-English summary — without searching the web or reading Slack channels.

## When to use

- Summarising a report, contract, proposal, or spreadsheet someone sent you
- Turning a long document into bullet points for a meeting
- Explaining a file in simple language for a colleague

## What the person must provide

1. **The file** — attach or upload the document (PDF, DOCX, XLSX, CSV, TXT, or MD).
2. **What they want** — one short sentence is enough.

Examples:

- "Summarise this report in 5 bullet points."
- "What are the main numbers in this spreadsheet?"
- "Explain this contract in plain English — what do we need to know?"

Optional: say how long the answer should be ("3 bullets" or "one paragraph").

## Steps (for the agent)

1. **Read the file** — Open the uploaded document only. Do not search the internet or Slack.
2. **Understand the request** — Restate what kind of summary they asked for. If the file is missing or unreadable, say so and stop.
3. **Write the summary** — In plain English, include:
  - **Overview** (2–3 sentences: what the document is about)
  - **Main points** (5–7 bullet points, or fewer if they asked for short)
  - **Numbers or dates** (only if the file contains them — list clearly)
  - **Action items** (anything the reader should do next, or "None stated")
4. **Return the answer** — Reply with the summary in the same place they sent the request (thread, portal, or chat). Do not post anywhere else unless they asked.



## Rules

- Use **only** the uploaded file. Do not guess content that is not in the document.
- If something is unclear in the file, say "The document does not say" instead of inventing an answer.
- Keep language simple — no jargon unless the document requires it, then explain it briefly.
- Stay under 300 words unless they asked for more detail.
